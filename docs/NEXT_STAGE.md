# Next-stage decision, not executed experiments

**Decision after the locked pilot:** the candidate did not beat MAXSET on H1
(−0.47pp, conditional 95% CI [−1.23,+0.32]pp). Do not scale this residual merger
as a validated improvement. Keep the complete negative-result archive, and move
the research agenda toward representation sufficiency for future unions.
This decision was made after results and is not a substitute primary endpoint.
First diagnose the large shared-backbone fit variability before attributing
all failures to memory composition.

## Gate 1: mechanism

The locked pilot asks whether a learned symmetric merger has a defensible benefit
over strong pooling under overlap. A negative result should stop a scale-up based
on that method. Do not treat better state reconstruction alone as useful memory.
Inspect the union reference's accuracy first: if it is weak, the experiment may
not distinguish a merger failure from an insufficient encoder/reader.

## Gate 2: proper architecture comparison

Train sum and max writers/readers separately, with matched optimization budget.
Compare learned merge operators with DeepSets pair aggregators and an explicit
relation-table reference. Add an ablation matching the candidate's extra training
and parameter budget. The first pilot uses a shared representation and cannot
settle this stronger comparison.

Increase the number of independently varying relations/entities enough that the
state is meaningfully constrained. Hold memory bytes fixed; publish capacity,
interference and abstention curves. Do not make capacity claims from N=6.

## Gate 3: algebra and update behavior

Test three or more parties, different merge trees, overlapping source histories,
redelivery, and merge-then-write. Distinguish duplicate reports of one event from
independent observations. Define time and conflict semantics before adding
correction tasks. A symmetric pair operator alone provides no convergence theorem.

## Gate 4: language backbone

Integrate a trained writer/readout directly with an open-weight language model's
hidden representations, or modify a hybrid recurrent state's update interface.
The model must use neural state during generation. Converting a toy reader's
answer into a text prompt would only demonstrate an external solver integration.

Freeze backbone/model versions, adapters, data splits, memory precision and all
compute costs in a new protocol. Start with a small model and measure resources
before scheduling a large training campaign. Compare to matched-budget text
memory, compressed KV, sum/max neural state, and replay references. No experiment
in this repository should be described as that backbone study until it runs.

## A potentially stronger research question

Which learned state representations are sufficient for **future union queries**,
rather than merely their own current queries? Local task accuracy can discard
distinctions needed after a later merge. Test this by constructing locally
indistinguishable histories that differ after adding the same third stream.
The theory document states the exact compatibility condition. Learning a useful
representation under this constraint remains an open method-development task,
not a claim already established by the present residual merger.
