# 不重看经历，能合并记忆吗？

**研究方向：固定容量神经状态的分布式合并与组合推理**  
*Can Memories Be Merged Without Replaying Experience?*  
开题简报与首轮结论｜2026-10-09｜合成神经记忆试验已完成，真实 LLM 阶段尚未执行

**目前判断：方向保留，当前残差合并器的优越性未成立。** 三个固定预算模型的预定主结果为：候选 78.85%，MAXSET 79.33%，差值 −0.47 个百分点，条件性 95% 区间 [−1.23, +0.32]。因此先保留负结果，重新研究“怎样的表示足以支持未来合并”，不据此扩大当前方法。

## 我们要解决什么

现在的代理可以分别完成工作，也可以交换文本或中间表示。但当两个代理各自积累了经历，能否直接把它们的记忆合成一个同样大小的内部状态，让合并后的系统知道双方知道的事，并回答必须联合这些信息才能解决的新问题？

我们的核心问题是：**不重新读取旧经历，不把两份记忆一直拼接变长，只合并固定容量的神经状态，能保留多少关系与推理能力？**

这对应一个具体用途：个人助理、手机端助理和项目代理各自处理不同信息，之后需要同步经验。比如，素材代理知道“某片段属于哪个项目”，交付代理知道“该项目允许哪些使用方式”。目标是让合并后的代理判断某片段能否用于一次新交付。更简单的关系示例是：A 知道“某人使用某车型”，B 知道“该车型满足某维修条件”，联合查询才得到完整答案。这些是目标场景，当前原型尚未支持真实项目授权判断或车辆维修建议。

实用价值在于降低重新处理旧经历的依赖，并让分散经历可以组合。实际节省多少存储、计算和延迟，需要另做测量；固定输出状态本身不能证明效率优势。

## 为什么还值得做

这个方向有很近的先例。我们的区别需要经实验建立，不能靠重新命名记忆模块。

| 邻近原始工作 | 已有贡献 | 本项目需要补上的证据 |
|---|---|---|
| [Cache Merging，2026，v2](https://arxiv.org/abs/2607.01308v2) | 合并 KV 片段集合，获得收敛状态与重复吸收；已有分割证据推理实验 | 不断增加独立片段时，固定大小的压缩状态能否仍支持组合查询 |
| [Federated Many-to-One Hopfield，2026](https://arxiv.org/abs/2603.19902) | 聚合各客户端的关联算子，不集中重放原始样本 | 任意实体关系绑定与跨代理问答，是否超出简单关联算子聚合 |
| [Deep Sets，2017](https://arxiv.org/abs/1703.06114)、[PointNet，2017](https://arxiv.org/abs/1612.00593) | 学习排列不变集合表示与对称池化 | 学习合并器是否优于充分训练的求和、最大池化等强基线 |
| [Mergeable Summaries，2012/2013](https://users.cs.duke.edu/~pankaj/publications/papers/merge-summ.pdf) | 在容量与误差约束下合并紧凑摘要 | 神经关系记忆的具体能力、失败机制与容量代价 |

潜在状态交流、可合并摘要和交换律都已有研究。当前有希望的贡献是：**把固定容量、独立经历、联合必要查询和合并后的可靠性放在同一套可审查实验里，量化哪些结构有效、在哪些条件下失效。** 这仍是待验证的贡献定位，不是优先权保证。详细比较见 [文献与方法审计](LITERATURE_AUDIT.md)。

## 方法与三阶段路线

每个代理把本地事件写成状态 \(M_A\)、\(M_B\)。合并器只读取这两个状态，输出同容量的 \(M_{AB}\)；读出器随后收到查询。合并时没有旧文本、参考答案或隐藏事件库。需要区分三个目标：联合信息答对问题；交付顺序与重复交付不破坏结果；新经历进入之后仍能正确更新。

### 第一阶段：先验证受控机制

使用六个实体、两种随机关系的小世界，检查关键事实分属双方时，学习合并器能否优于指定的 MAXSET 对照。每份输出状态为 **1,152 bytes**，共同编码器与读出器先训练并冻结，再分别训练候选合并器与 DeepSets 对照。

当前 [本地预注册](PREREGISTRATION.md) 规定三个训练种子、三种重叠水平，每个拟合模型评价 3,000 个世界、每个世界四条查询。主比较固定为：重叠概率 0.50 条件下，已知答案的两跳查询，学习方法减 MAXSET 的世界平均准确率差。只有预定的条件性 95% bootstrap 区间下界高于零，才支持这一窄假设。

**完成标准：** 保存冻结记录、训练日志、最终检查点与逐世界预测；主统计可以从保存数据重算；单方状态、空状态、错配另一世界证据等控制完整报告。候选获得了额外训练，所以这不是所有方法总训练成本相同的比较。

**失败闸门：** 发现答案泄漏、预算遗漏或不可重现时，先修实现并记录修订；主假设不支持时，照实报告。若 DeepSets 或简单方法更强，不能改换主比较来宣布成功。这个小世界预算宽裕，结果不能证明强压缩、LLM 效果或一般认知架构。

### 第二阶段：检验容量、合并结构与持续更新

另行冻结新协议，增加关系数、干扰和代理数量，在相同字节预算下画能力曲线。用同一世界的三方或更多证据分割测试合并树；分别测试相同状态重投递与独立经历重叠。加入新事实和明确规则的更正，观察该改的关系是否改掉、无关关系是否保留。时间与来源信息若进入状态，也计入预算。

**完成标准：** 在训练可比的强基线上报告组合正确率、重复交付稳定性、合并树差异、更新正确率及持久字节数。交换、结合、幂等分别检查；普通对称网络不能自动获得全部保证。

**失败闸门：** 收益只来自增加状态、读取旧经历或更大训练成本；简单 max 已解释全部效果；多次合并或更正导致明显错误固化。出现这些结果，就收窄方法主张，转向容量与失败机制研究。第二阶段不能追认成第一阶段的预定成功标准。

### 第三阶段：接入真实语言骨干

在实际开源语言模型上接入状态读写与合并模块，先用可核验的个人助理和项目协作任务，检验自然语言表述、别名及未见场景。与文本记忆、重放参考及简单潜在合并比较，统一可见证据和持久预算，单独计入适配训练及峰值计算开销。

**完成标准：** 真实骨干、数据与适配过程可复现；跨代理信息确实是答对所必需；收益在新任务上保留，并给出端到端成本。每个扩展都在评价前固定协议。

**失败闸门：** 合成世界的效果无法迁移；自然语言结构误差抵消收益；现有简单方法更可靠或更便宜。此时保留经过验证的合成实验结论，不把它包装成通用 LLM 记忆突破。

## 预期论文贡献与交付

论文可以由三部分组成：一个明确的固定容量分布式记忆问题；带泄漏控制、强基线和容量统计的评测；经过验证的方法或失败机制。基础状态碰撞与容量论证应标为标准限制，不当作新定理。合并、纠错和来源管理的实验结果分别支持各自结论，不互相替代。

本地交付包含方向简报、文献审计、预注册、协议审查、源代码、配置、测试和实际运行产物。发表级别与最终论文主张，需要等实测结果和真实语言阶段的证据再判断。

这个结果不否定整个神经记忆方向。它具体否定了当前证据足以支持“多加一个对称合并网络就比强池化更好”的判断。现在的成果是一份真实运行、保留负结果的研究草稿和审计工程，尚不是可宣称突破的完整 LLM 论文。

正式实测结论以保存的机器可读结果和报告为准。任何测试后提出的新分析都标明探索性质。
