# 给研究负责人的说明

**建议先验证模型能否稳定学会任务，再投入正式的容量实验。**
第一阶段的结论仍然成立。学出来的对称合并器准确率是 **78.85%**，
简单的 MAXSET 是 **79.33%**，数据没有支持原先“学出来的合并器更好”的假设。

**这次看到了编码时真正丢掉的信息。** 我们给旧模型两份几乎一样的记录，
只改一条关系，再分别接上同一条来自另一方的线索。最弱的旧模型用
MAXSET 时，有两对记录被压成了完全相同的状态，但正确答案分别不同。
压缩完成后，后续合并器拿到的输入一模一样，无法同时答对。另一方面，
同一个旧模型用求和保存时，专门训练的小读出器能找回 **85.50%** 的关键关系；
原读出器在合并后答两跳问题只对了 **52.52%**。所以，下一轮要分别排查
“没存下来”和“存下来了但读不出来”。

**换顺序和重复投递是两件事。** 对称合并器可以交换两个输入，
但三个参与者先合并哪两方，仍可能改变答案。在有重叠证据的三方小试中，
对称合并器第一次合并后答对 **79.34%**，同一方的状态额外送达八次后，
准确率降到 **38.19%**。MAXSET 在同一组测试中始终是 **80.38%**。
这里每一道题需要其中两方的证据，三道题合起来覆盖三方。
如果研究目标要求一道题同时用到三方证据，还需要新任务和读出设计。

**容量实验暴露的是学习失败。** 给同一批结构化题目 32、96 或 192 字节，
神经模型在短训练预算下几乎总答“不知道”，连从完整证据直接生成的记忆也一样。
用相同字节存关系表，能放下全部键时答对 **100%**。最紧的 32 字节、
8 种关系条件下只能保留部分键，在两种重叠条件下分别答对 **42.02%**
和 **38.03%**。这证明了比较基线有价值，但还无法估计学出来的记忆
能存多少。

**下一次需要你决定的是验证预算和通过门槛。** 建议先选一个曾经能学会的
简单任务和一个新的容量测试点，用新种子确认完整证据能否被稳定读出来。
只有过了这关，再花更大的训练预算比较谁压缩得更好，以及谁能应对重复投递。
如果最终目标只是在这个结构化任务里合并记录，现有关系表已经给出了很高的标准。
如果目标是处理难以事先定义字段的经历，还需要专门设计能验证这一优势的任务。
