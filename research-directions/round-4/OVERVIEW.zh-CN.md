# 第四轮：五个新的科研方向与选题

**日期：2026-10-16。**这是五份简要开题稿，尚未运行、注册或投稿。文献核查只用于识别近邻和缩小问题，不代表已经证明无人研究过。

| 课题 | 一句话问题 | 实用场景 |
|---|---|---|
| 跨语言记忆更新一致性 | 中文记住、英文纠正，换一种语言问时还会不会答旧版本？ | 双语助手、国际团队 |
| 潜在记忆的局部纠正 | 改掉一条记忆，能否更新相关后果，又不弄坏其他事实？ | 用户可控的神经记忆 |
| 多模态关联绑定 | 换了衣服、背景或提示形式，还能把人、物、事件正确关联吗？ | 视觉助手、个人媒体检索 |
| 带契约的技能记忆组合 | 两个以前都成功的流程，在工具更新后还接得起来吗？ | 编程、工作流 agent |
| 带搜索覆盖范围的负向记忆 | 如何记住“这次没搜到”，又不误记成“根本不存在”？ | 科研检索、代码搜索 |

## 1. One Memory, Many Languages

重点研究跨语言的纠正、别名和适用范围，而不只是“英文存、中文搜”。实验用同一个事实账本生成不同语言版本，组合写入语言、纠正语言、查询语言，并用人工语义复核与正确证据直接输入来拆分翻译、检索和记忆错误。已有多语言 embedding 和 Hindsight 等系统，因此新贡献只能落在持续更新的一致性上。[完整稿](01_crosslingual_updates.md)

## 2. Correct One Fact, Preserve the Rest

这是本轮架构问题最直接的一项：让用户能修正压缩后的数值记忆。评测同时看三件事：目标改对了吗、真正依赖它的结论更新了吗、无关事实是否仍然正确。已有 Larimar 和 MQuAKE 涉及记忆编辑与知识传播；新稿限定为没有原始历史回放时，对固定容量 episodic state 的局部修正，并加入多次修改和撤销的成本核算。[完整稿](02_local_latent_correction.md)

## 3. Who Goes with What?

这个最贴近你原来举的“看到这个人，就联想到他的车”的例子。用受控的虚构人物和物品相册，改变服装、背景、查询模态和误导线索，检查系统记住的是正确关联还是表面共现。ICM-Bench 和 M3Exam 已有身份及多模态记忆评测，因此必须加入成对线索干预，并把视觉识别能力与记忆绑定能力分开。[完整稿](03_crossmodal_binding.md)

## 4. Skills That Compose

让经验从“以前这样做成功了”变成带有输入条件、输出保证和版本限制的可组合流程。实验改变工具接口或副作用，检查前一个技能的输出是否仍满足后一个技能的前提。Skill-Pro、SkillComposer、BASM 已覆盖技能复用、排序与边界，所以本稿只研究组合接口在工具变化下是否可执行验证，并与普通类型检查比较。[完整稿](04_skill_contract_composition.md)

## 5. Not Found Is Not False

科研助手经常搜索失败；如果把失败结果长期记成“不存在”，以后会主动漏掉信息。新稿将负向观察绑定到查询、集合、快照和覆盖范围，分别测试完整枚举与 top-k 没命中。已有失败经验记忆和不确定性评测，因此新点限定为搜索覆盖的有效范围。这个题最适合先做便宜、可精确评分的诊断；有限集合的完整搜索不能被包装成对全网不存在性的证明。[完整稿](05_coverage_aware_negative_memory.md)

每项都补齐了假设、最小实验、强对照、主要指标和停止标准。建议优先认真比较第 2 项的架构收益，或先用第 5 项快速建立可信实验；不需要五项一起投入训练。[全部课题总导航](../INDEX.zh-CN.md)保留前面九项与这轮五项的入口。
